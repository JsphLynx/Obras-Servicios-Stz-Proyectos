# Obras-Servicios-Stz-Proyectos
Aplicación web para el Departamento de Obras y Servicios de Santurtzi. Versión 1.0 para demostración y prácticas: 10 proyectos sintéticos protegidos, entorno de prácticas aislado, permisos por usuario y manuales. Gestiona obras, mantenimiento, presupuestos, certificaciones, facturas y pagos con Neon PostgreSQL.
