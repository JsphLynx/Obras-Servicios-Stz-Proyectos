# Contribuir o revisar

Empieza por `README.md`, `docs/arquitectura.md` y `docs/alcance.md`. Las propuestas deben indicar el problema, el comportamiento esperado y cómo comprobarlo con datos sintéticos.

Antes de proponer cambios: `pnpm test:unit`, `pnpm typecheck` y `pnpm build`. Los escenarios de integración requieren infraestructura QA y preparación previa; no apuntes las pruebas a la demostración compartida. No añadas credenciales, cuentas personales, capturas con información privada ni volcados de datos.

Utiliza una rama y una pull request con alcance acotado. Las ampliaciones de Azure, Microsoft 365, Copilot o uso con datos reales deben describir su propio criterio de aceptación; no forman parte del cierre 1.0.
